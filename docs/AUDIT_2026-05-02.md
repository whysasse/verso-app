# Verso — Cross-Artefact Audit

**Date:** 2026-05-02
**Scope:** Repo files, docs/, Linear issues (all states), Figma file (variables, styles, components, frames)
**Status:** Findings + decisions ready for execution

---

## Executive Summary

Verso is in design phase with a healthy spine: 89 Linear issues, ~25 design docs, a connected Figma file with 24 variables and 30 text styles, and a small Swift design-system foundation. The audit found **27 drift items** across four sources. Most are low-risk and easy to fix; six required a decision and have been answered. The biggest hidden risk was a **second, undocumented set of text styles** in Figma — caught by the audit.

After this audit, the docs folder shrinks from 32 files to 22 (removing 10 stale or duplicate files), CLAUDE.md / README.md / AGENTS.md become accurate again, and all four sources tell the same story about tokens, components, and the onboarding flow.

### E. Figma drift

#### E1. Empty-state frames mislabeled (4 frames)
Each theme on the Home page has 4 empty-state frames named: `Empty — All`, `Empty — Unread`, `Empty — Reading`, `Empty — Reading`. The duplicate is almost certainly supposed to be `Empty — Read`.

| Frame ID | Current name | Should be |
|---|---|---|
| `42:2027` | Paper / Empty — Reading | Paper / Empty — Read |
| `42:2034` | Sepia / Empty — Reading | Sepia / Empty — Read |
| `42:2041` | Night / Empty — Reading | Night / Empty — Read |
| `42:2048` | Ink / Empty — Reading | Ink / Empty — Read |

(Verify which of each pair is the duplicate before renaming.)

#### E2. `figma_get_styles` API gap (not Verso's drift, just a tooling note)
The standard `figma_get_styles` returned `[]` while `figma_get_text_styles` returned 30. Use `figma_get_text_styles` for any future style audits — `figma_get_styles` looks like it only returns published styles.

#### E3. Figma summary tool is misleading
`figma_get_design_system_summary` reports `tokens.colors.count: 0`, `tokens.spacing.count: 0`, `tokens.typography.count: 0` despite all of these existing as variables. Use `figma_get_variables` and `figma_get_text_styles` directly.
